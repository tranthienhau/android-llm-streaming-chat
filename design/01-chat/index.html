Can you explain how Server-Sent Events (SSE) work for streaming AI responses?

Server-Sent Events (SSE) is a web technology that allows a server to push real-time updates to a web page over a single HTTP connection. In the context of AI assistants like me, it's used to "stream" tokens as they are generated.

data: {"text": "Hello"}
data: {"text": " world"}
data: {"text": "!"}

What are the main benefits compared to WebSockets?

SSE is often preferred for streaming LLM responses because it's unidirectional—the server sends data to the client, which is exactly what's needed for text generation.

Key advantages include:
1. Lightweight: Uses standard HTTP instead of a custom protocol.
2. Auto-reconnect: Browsers handle reconnections natively.
3. Firewall friendly: It works over standard port 80/443 without issues.
